# Product Overview

The website-owned AHA runtime is a universal assistance engine for merchant
websites.

## What The Product Is

- a manifest-driven runtime
- a launcher UI that can be embedded in a site shell
- a visible activity surface so users can see progress
- a planner / permission / execution pipeline
- a rollout, audit, and replay layer
- stack-specific adapters for easier installation
- a visible progress panel or activity log in the adapter layer

## What The Product Is Not

- not a per-client custom bot
- not a backend data access tool
- not a replacement for the merchant's own site code
- not a stack-specific rewrite for every customer

## v1 Shipping Order

1. Universal core
2. Next.js / React reference adapter
3. Shopify adapter
4. WooCommerce / WordPress adapter
5. Adobe Commerce / Magento adapter
6. Generic fallback contract

## The Buyer

Usually the buyer is:

- the merchant owner
- the ecommerce lead
- the engineering lead
- an agency building stores for clients

## The Value

The product is worth buying if it:

- reduces support cost
- improves conversion
- automates repetitive assistance
- stays safe around payments and other sensitive steps
- works across the merchant's chosen stack without custom engine work
